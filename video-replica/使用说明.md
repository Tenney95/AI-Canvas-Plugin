# 视频复刻插件

本插件默认一键复刻完整参考视频：按所选模型能力分段，准备控制素材、提取音频、转写对白，
逐段调用模型后合成完整视频。也可手动打点指定切分位置，或在高级模式编辑分镜和提示词。
控制视频保留空间位置、动作或轮廓；重新生成的角色、风格和细节由视频模型决定，不能保证逐帧一致。

## 安装与操作

1. 使用支持 Python 原生媒体 artifact 的新版 AI Canvas，在插件设置页安装本目录的 Manifest。
2. 启用时完成宿主的可信 Python 原生确认。Python 插件以当前用户权限运行，应先审阅源码。
3. 选择一个已有的本地视频源或已生成视频节点，通过工具栏或右键的“视频复刻”打开面板。
4. 选择应用已配置的视频模型或 ComfyUI 工作流；填入替换角色、场景与风格，点击“一键复刻”。无需先检测镜头、抽取关键帧或手写逐镜提示词。
5. 默认保留原片对白、音乐与环境音，并启用本地语音转写。首次缺少语音模型时先显示下载提示，点击“下载语音模型并继续”后才下载。
6. 面板显示完整覆盖原片的预计生成段和费用提示。每个生成段调用视频模型；选择视觉分析模型时另有分析开销。宿主后台负责控制素材、生成片段和成片。
7. 可关闭面板让宿主继续，也可“查询任务状态”或“停止任务”。重开面板复用已有任务，状态不确定时不会自动重投付费请求。

## 自动分段与手动打点

生成段上限来自宿主提供的模型能力，单段最多 30 秒。例如所选模型允许 30 秒时，1 分钟分成
2 段；允许 15 秒时分成 4 段。ComfyUI 或未声明时长能力的模型显示段长设置，默认 15 秒，
需要与已导入工作流的实际输出时长一致。具体参考视频数量、单份时长、音频输入和分辨率限制仍由宿主预检。

在时间轴拖动位置、输入秒数后点击“添加切点”，或加载播放预览后在当前播放位置打点。
点击切点旁的 × 删除，“恢复自动分段”清空所有手动点。首尾固定覆盖完整原片，超出模型上限的
手动区间会继续拆分。界面显示最终预计分段；不会只处理最初的 15 秒或静默漏掉超长部分。
当前完整视频最长 300 秒、最多 64 个生成段；超过范围在生成前拒绝。

模型只支持固定时长或短尾段低于最低时长时，宿主按合法时长准备参考输入；控制视频可复制尾帧延长，
最终合成按原片区间裁剪。生成结果短于目标区间视为失败，不能通过拉长播放时长冒充成功。

## 音频与对白

- “保留原片对白、音乐与环境音”：成片使用原片音轨，覆盖生成片段的声音。更换角色不会自动克隆声音或改变说话人。
- “使用模型生成音频”：保留生成片段的音轨；是否有声音取决于模型或 ComfyUI 工作流。
- “静音”：成片不包含音轨。

本地语音识别从原片提取音频并生成对白文本，用于分段提示词和画布对白文档。时间定位以识别分块区间为依据，
不能当作词级对齐或精确字幕。没有语音或没有音轨时不编造对白。控制视频始终无音轨；
是否能同时向模型传入控制视频和音频由宿主模型能力预检，不能仅靠提示词代替媒体输入。

## 高级镜头与物料

点击“高级：手动镜头与物料”保留原有流程：检测镜头、校正入出点、抽取关键帧，
选择视觉模型分析或手写提示词，生成分镜表、Markdown、参考帧及深度/骨架/线稿。
生成方式可选仅制作物料、视频模型或 ComfyUI；后两种创建每镜 AI 视频节点并由宿主串行生成。
高级模式保持每批最多 6 镜、每镜最多 15 秒、最多 25 节点的原有限制。

替换角色、替换场景和逐镜提示词支持输入 `@` 或点击引用按钮，使用与应用相同的 MentionPicker 图卡选择连线节点、角色库角色/场景/道具或资源库图片。
支持搜索、分页、方向键/Enter/Escape 和鼠标选择；输入法组字期间不会触发查询。
搜索按钮位于三个来源页签的同一外框内，点击后输入框向左展开，页签同步向左移出；按钮背景跟随深浅主题。
搜索按当前选中的来源查询。点一次 × 或在搜索框内按 Esc 即收起，恢复正文中 `@` 的原查询与光标；正文内 Esc 关闭整个选择器。
候选增减时外框高度和位置同步过渡，列表只滚动自身，系统减少动态效果时直接切换。查询失败和分页按钮仍在选择器内，底部不重复显示加载状态。
缩略图由宿主按需重编码为最长边 160 像素、最多 8 KiB 的 JPEG，无法取得时显示本地图标。插件不取得素材原生路径或远程 URL。
选择后可继续补充服装、动作、光线等文字要求；角色和场景引用应用于每个镜头，逐镜引用只进入对应镜头。
引用在插件内使用宿主签发的不透明 token，宿主在分析和输出准备阶段解析并转换为应用引用，
再由正常生成批次取得素材。Python 仅保留引用 token，角色和场景素材的正文、原生路径与凭据不通过引用传入 Python。

## 准备 Python 环境

宿主使用插件设置页显示的 Python 和该解释器的 site-packages。AI Canvas 不会自动安装依赖，
也不会自动切换到本目录里的虚拟环境。安装依赖后重启 AI Canvas，确认解释器版本一致。

仅使用线稿：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\prepare-runtime.ps1 -Mode Canny
```

启用深度和骨架，并显式下载 Small / DWPose 模型：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\prepare-runtime.ps1 -Mode Full -DownloadModels
```

`Full` 保留已可用的 Torch / TorchVision；缺失时默认安装 CPU PyTorch。NVIDIA 用户可通过 `-TorchIndex` 指定与驱动兼容的官方 wheel 索引。
可以使用 `-Python` 指定宿主已选择的解释器。不要把 `-Python` 指向宿主不会探测的任意环境。
模型缓存需由与应用相同的系统用户准备；插件运行阶段强制离线，不会临时下载权重或执行 pip。
准备脚本先使用 Hugging Face 下载器；若网络剥离 HEAD 元数据，则以固定 revision 从官方 HTTPS 地址
流式 GET 到临时文件。三份文件均按官方 LFS 大小和 ReShot 上游固定 SHA-256 验证，通过后才进入离线缓存。
损坏的已有缓存拒绝覆盖，不更改持久化镜像端点设置。

线稿使用 OpenCV Canny + FFmpeg，不加载模型。深度使用 ReShot 0.5.0 的 Video Depth Anything Small；
骨架使用 DWPose 并启用追踪和平滑，不画脸部点。ReShot 的大型非商业权重未纳入插件。

## 本地处理批次边界

- 高级模式每批 1–6 个镜头，每镜大于 0 秒且不超过 15 秒。自动任务使用独立 `replicate-segment` 操作准备材料，每份区间和参考目标时长最多 30 秒；全部按时间排序、不重叠。
- 每批最多 25 个节点：2 个方案节点 + 关键帧数 + 镜头数 × 控制类型数 + 生成节点数。生成节点数在仅物料时为 0，其余方式为镜头数。
- 本地处理按镜头串行，控制视频 24fps、长边最多 1280 像素；输出文件为 H.264 MP4，无音轨。
- 宿主保留 120 秒总期限，插件在 110 秒内结束。CPU 深度或较多镜头容易超时，应缩小批次或改用线稿。
- ReShot 保留内存预算拒绝逻辑，不强行执行可能耗尽内存的片段。默认 Small + fast；CUDA 可用时由 ReShot 自行选择。
- 这些输出没有承诺满足所有生成厂商的分辨率、比例与文件体积要求；提交前按目标模型要求检查。

## 数据与取消

宿主授予的路径仅进入本次可信 Python 进程，返回数据只含资源句柄、安全文件名及镜头文字。
API Key 仍由宿主凭据存储管理；插件不会读取、保存或输出 Key。第三方日志与完整 metrics 不写入结果。
取消、超时、项目/节点/plugin revision 变化时，宿主终止进程树并清理本次原生 job 目录，整批画布结果不提交。
Python 进程管理是生命周期边界，不是操作系统沙箱。

模型与 ComfyUI 请求由宿主生成批次负责，插件不接收 API Key、厂商 URL、工作流正文或输出路径。
视频模型调用可能产生费用。提交后生成状态不确定时不自动重投，请先核对已有视频节点与厂商任务；
切换项目、关闭面板或重复打开面板不会作为重新生成授权。

## 界面源码与构建

`src/ui.js` 是可编辑源码，`ui.js` 是安装用的单文件 IIFE 产物。构建脚本直接导入宿主
`MentionPicker.tsx`、`mention-picker.css` 和基础主题变量，使用宿主已有 React、Iconify、Lucide、
esbuild、PostCSS/Tailwind 依赖；不复制选取器样式，不新增 npm 依赖。固定图标离线打包，无图标 CDN 请求。
打包的共享宿主 UI 保留宿主 Source-Available 许可；React、React DOM、Iconify React、Lucide React
各自许可全文随 UI 产物保留。插件自身 Apache-2.0 声明不对这些共享组件或第三方依赖重新许可。

node tools/build-ui.mjs --host ..\..\AI-Canvas-tauri
